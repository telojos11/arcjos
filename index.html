Permissions-Policy Enforcement Gap

Header: Permissions-Policy: storage-access=()

⚠️ POLICY ENFORCEMENT GAP CONFIRMED:
Permissions-Policy: storage-access=() blocks requestStorageAccess()
but does NOT revoke existing grants. hasStorageAccess() returns TRUE
and cookies are accessible with unpartitioned access.

Impact: If a malicious iframe obtains a Storage Access grant via
navigation IPC bypass (crbug 498417152), the embedder's Permissions-Policy
provides zero protection — the grant persists and allows cross-site tracking.
